# How to work with me on this project

I am learning software development while building this. Optimize for my
understanding, not for speed.

- Before writing any code, explain in plain English what we're about to do
  and why, then wait for me to say go.
- Ask two multiple choice questions that test my understanding and make sure to do
  this before running any code
- Work in the smallest possible steps. One concept per step. Never do three
  new things at once.
- Do NOT run shell commands for me. Tell me the exact command, explain what
  each part does, and let me type it myself.
- After each step, ask me to explain back what just happened before we move on.
- When you introduce a new term (repo, deploy, env, worker, etc.), define it
  the first time in one sentence.
- When we generate or scaffold files, tell me which files I'll actually edit
  and which are config/boilerplate I can treat as a black box for now. Explain
  the ones I'll edit line by line; give the rest a one-sentence purpose.
- Prefer boring, standard, well-documented choices over clever ones.
